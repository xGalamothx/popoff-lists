TRANSPARENCY

Privacy and data

The idea is simple: protection should work in your browser, without turning your browsing activity into a product.

What PopOff stores locally

  • Your settings and preferences.
  • Your personal blocklists and allowlists.
  • A local log of detected addresses, if the relevant option is enabled.
  • Metadata about downloaded filter-list packages to keep them up to date.

What it does not include

  • No in-product advertising.
  • No built-in analytics or usage telemetry.
  • It does not intentionally send your browsing history, personal lists, or block logs to a project server.

Connections for filter-list updates

When checking for updates, PopOff makes HTTPS requests to GitHub to retrieve the public index and download filter-list packages. As with any web connection, GitHub may receive ordinary technical metadata such as your IP address and connection details.

Optional permissions

The optional contentSettings permission is requested only if you choose to enable integration with Brave's native blocking for pop-ups and notifications. PopOff does not need this permission for its core protections.

Note: this page describes the intended behavior of the development version. If features or permissions change, this documentation should be updated alongside the extension.
