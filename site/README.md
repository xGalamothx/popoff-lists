# Sitio documental de PopOff

Este directorio contiene el sitio estático público de presentación y documentación de PopOff.

- `index.html`: página de inicio.
- `docs.html`: descripción funcional y arquitectura de alto nivel.
- `privacy.html`: resumen de privacidad y permisos.
- `contribute.html`: historia del proyecto y formas de apoyar.
- `styles.css` y `script.js`: presentación responsive y navegación móvil.

No se cargan fuentes, scripts de analítica ni recursos de terceros. El botón de apoyo enlaza a la página Ko-fi del creador.

Los cambios en `site/**` se publican mediante `.github/workflows/deploy-site.yml`. Para la primera publicación, el administrador debe habilitar GitHub Pages en Settings → Pages y seleccionar GitHub Actions como origen de despliegue.
