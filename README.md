# popoff-lists

Repositorio público de paquetes de listas para PopOff.

## Documentación del proyecto

La web de presentación y documentación está en la carpeta [site/](site/). Su dirección prevista en GitHub Pages es:

https://xgalamothx.github.io/popoff-lists/

La primera publicación requiere habilitar GitHub Pages para este repositorio desde **Settings → Pages → Build and deployment → GitHub Actions**. Después, el flujo automático publicará los cambios de la carpeta `site/`.

El sitio documental es independiente del código privado de protección de la extensión.
